# Automatic License Plate Detection (ALPD)

This project detects vehicle license plates from images using
OpenCV for image processing and EasyOCR for text recognition.

---

## 🚀 Features
- Noise reduction using bilateral filtering
- Edge detection using Canny
- Contour-based license plate detection
- OCR-based number plate recognition
- Displays detected plate and text on image

---

## 🧠 Tech Stack
- Python
- OpenCV
- EasyOCR
- NumPy
- Imutils
